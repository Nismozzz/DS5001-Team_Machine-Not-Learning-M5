# 摘要

本部分把预测结果换算成库存成本，回答一个运营问题：在给定补货与服务水平的条件下，多花的建模成本是否换来了更低的库存成本。结论基于模块 02 全量交付包，覆盖 30,490 条序列（CA 4 家、TX 3 家、WI 3 家门店）与四个可评分窗口（d_1829、d_1857、d_1885、d_1913），分位网格 23 点（0.50、2/3、0.80 至 0.99 每 0.01、5/6），成本比 1:1、2:1、5:1、9:1，仿真连做四期并期末结转。一次正式运行产出 17 项文件，耗时 1,408.6 秒（Python 3.12.16 与 pandas 2.2.3 单机串行），11 项验收全部通过。

核心发现三条。其一，精度差距小于预期：商品层 WAPE 为 LightGBM 0.7399、指数平滑 0.7406、TSB 0.7466、季节朴素 0.8752，前三者相差不到 0.01。其二，成本差距明显更大：服务水平 0.95 下每件需求成本以 LightGBM 最低，四个成本比依次 0.603、0.626、0.694、0.785，比 TSB 低 12.7% 至 26.4%，比指数平滑低 14.7% 至 30.7%，成本比越高优势越大。其三，覆盖率是唯一系统性弱点：名义 0.95 下实测 0.9231 至 0.9434，LightGBM 带宽偏窄，需抬到 0.9617 才达 0.94 覆盖；全网格 368 行中 39 行偏离超 0.05，集中在低分位。

可复现性由独立复算证明：不复用模块内部函数、直接从交付文件重算，WAPE 与存档值最大差 4.4×10⁻¹⁶，覆盖率差 1.1×10⁻¹⁶，成本加总相对误差 3.96×10⁻¹⁶，重采样点估计三条全同；另一次独立运行的 9 个数据文件字节完全一致。

边界同样明确：样本为 M5 数据集全部 30,490 条序列（10 家门店），成本按总需求归一化，绝对金额不可外推；模块 03 面板已逐行核验，点预测自洽、累计分位未调和，精度指标覆盖商品、门店、总量三层，库存成本、覆盖率与决策图（分段选型）只到商品层；仿真口径定为期初在手等同上期结转、28 天内不安排中间补货。


# 1　本部分的主要目的


## 1.1　在整体研究中的位置

项目是一条从预测走向运营决策的链条：模块 01 整理可复现输入，模块 02 产出点预测与分位预测，模块 03 处理分层与调和，模块 05 负责报告与展示。前三个模块都停留在预测侧，只能回答哪个模型误差更小。

模块 04 是唯一把预测换算成库存成本、也是唯一能判断建模投入是否值得的环节。没有这一环，全组只能得到精度排行榜，无法回答运营上该选哪个模型。


## 1.2　需要回答的三个问题

第一，精度差多少。在四个可评分窗口上计算 WAPE、MASE 与分位损失，商品、门店、总量三层都给，避免只报细粒度的好看数字。

第二，精度差能换多少成本差。在给定复核周期、服务水平与成本比下模拟四期库存，换算成每件需求承担的总成本。

第三，差异在什么范围内成立。按间歇性、生命周期、销量规模切分找分段最优，并用配对重采样估计不确定性。


# 2　输入与依赖


## 2.1　来自模块 01 的输入

模块 01 的交付是本部分唯一的真实数据来源，用到五类产物：切分清单、各滚动起点真实销量、长期销量宽表、需求分层表、层级映射表。已在本地按仓库说明完整重建并逐个复算哈希，95 个产物全部一致，写入输入联签文件（95/95），同时履行组内“每人实质复核一个非本人模块”的要求。


## 2.2　来自模块 02 的输入

模块 02 交付按滚动起点组织的预测面板，字段含序列、起点日、目标日、模型、层级、分位水平、预测类型与预测值。本次用四个可评分窗口的日级点预测与 28 天累计分位：LightGBM 的周期分位直接读出，三个基线只有点预测，其周期累计分位由本模块补造——这条必须写明，不能含糊成“模块 02 提供了全部分位”。

分位损失必须分两个口径。日级：LightGBM 用原生日分位，只有 0.5、0.9、0.95、0.99 四个水平；三个基线由点预测经累计层尺度比转成日级分位，23 个水平齐全，因此四模型只在四个共同水平可比，其余 19 个水平只有基线有值，不能跨模型排序。28 天累计层另按同一份目标离线重算，四模型同网格：0.95 时每序列平均损失 LightGBM 2.076、TSB 3.110、指数平滑 3.374、季节朴素 3.785，分别低 33.2%、38.5%、45.2%；23 个水平整体平均为 3.247、4.022、4.272、4.982，排序一致，低 19.3%、24.0%、34.8%。这组数由补充脚本重算，未改仿真，覆盖率与 mean_S 与报告逐位对齐。


## 2.3　来自模块 03 的输入

模块 03 交付分层结构与调和：12 层、42,840 个节点、30,490 条叶层序列、365,880 条成员关系，另有调和方法、诊断与验证报告（2,160 个预测文件、2,192 条清单条目，加性误差为零）。

两点要说明。其一，面板到位并完成核验：点预测确做了自下而上调和，顶层 28 天累计由 1,146,624 变为 1,189,844，精确等于叶层点预测之和；但 28 天累计分位的 bottom_up 输出当前仍是 unreconciled 的拷贝（实现缺口），因此面板自身不成加总关系——门店 CA_1 节点对叶求和低 14.2%，顶层 τ=0.95 低 35.4%，各节点最大 49.8%。这是 Module 3 的实现缺口，不是 bottom_up 的分位不可加性质。分层精度指标仍按商品、门店、总量三层给出，部分门店与州层改用点预测口径，分位口径不采用当前调和面板。其二，数据契约要求进入仿真前调用其分位调和接口：本部分已按方案 A 执行，补齐依赖后用交接包层级映射自建目录，对本侧商品层分位实调自下而上，输出与本侧逐层求和逐位相同、最大差为零，按单品下单的全部数值不变，口径差异已消解，但该接口核验不替代 M3 交付面板的修复；该接口只保证节点与叶层加总自洽，不修正门店层分位偏高，见 4.7 节。


# 3　结构与方法


## 3.1　流程构成

二十四个代码单元按职责分为六段：输入与窗口锁定、预测接入与质检、精度评估、库存仿真、结论呈现、固化与交接。


## 3.2　关键口径

仿真口径：复核周期 28 天、提前期为零、首期期初库存为零且此后各期期初等于上期结转、缺货不回补、期末剩余结转下期；订货目标为该周期 28 天累计需求的所选分位，订单量为目标与期初在手之差且不为负；成本为期末剩余乘持有单价加未满足需求乘缺货单价；满足率为已满足数量占实际需求之比（逐序列等权平均）。四个窗口首尾相接覆盖 d_1830 至 d_1941 共 112 天，故可连做四期；无真实标签的窗口只用于预测展示，不进成本仿真。

扫描维度为 23 个服务水平、四组成本比、四个模型，四个窗口各跑一遍：库存汇总 368 行（4 模型 × 23 水平 × 4 成本比）、逐窗口汇总 1,472 行、决策图 1,288 行。重采样固定种子 5001、200 次、配对方式，同批样本同时用于被比较的两个模型，抵消抽样规模噪声。


## 3.3　基线累计分位的构造

三个基线的周期累计分位不能直接可得，最终方案是对每个模型取更早窗口的 28 天累计误差经验分位，叠加到当期点预测后截断为非负；此前三轮尝试（整体缩放、单窗口加性、按模型池化加裁剪）均不稳。该方案在名义 0.95 下使三个基线得到 0.937 至 0.943 的实测覆盖，缺口 0.007 至 0.013；基线分位质量取决于可回看窗口数量而非公式形式，模块 02 若提供更多窗口可继续压缩。


# 4　主要结果


## 4.1　预测精度：差距在千分位量级

商品层 WAPE 四窗口：LightGBM 0.7481、0.7531、0.7377、0.7209，指数平滑 0.7438、0.7455、0.7512、0.7220，TSB 0.7481、0.7540、0.7501、0.7339，季节朴素 0.8710、0.8788、0.8889、0.8622；四窗口均值 0.7399、0.7406、0.7466、0.8752。前三者在任一窗口差距不超过 0.016，排序还随窗口切换，单看精度无法给出稳定排序。

MASE 按逐序列等权：指数平滑 1.1106、1.1634、1.3380、1.1974，TSB 1.1087、1.1514、1.3150、1.2032，LightGBM 1.1589、1.2024、1.3563、1.2345，季节朴素 1.2280、1.2895、1.4755、1.3527。TSB 在三个窗口最低，说明除以序列自身尺度后简单模型更有优势。

聚合层排序与商品层不同：门店层 WAPE 指数平滑 0.0868、LightGBM 0.0725、TSB 0.1509，总量层分别为 0.0649、0.0475、0.1289。聚合后误差普遍降一个数量级（商品层 0.74、门店层 0.07 至 0.15、总量层 0.05 至 0.13），LightGBM 在三个层级都不劣于基线；TSB 商品层与 LightGBM 只差 0.007，门店层却是其两倍，说明它的误差在门店内不易相互抵消。这不改成本结论（补货按单品执行），但对分层调和有直接含义：调和能修的是节点层的系统性偏差，单品层彼此独立的误差修不掉。


## 4.2　成本：模型差距随成本比放大

服务水平 0.95、每件需求成本（四窗口均值，成本比 1:1 / 2:1 / 5:1 / 9:1）：LightGBM 0.603、0.626、0.694、0.785，TSB 0.691、0.738、0.879、1.068，指数平滑 0.707、0.760、0.920、1.133，季节朴素 0.827、0.886、1.062、1.297。四个成本比下 LightGBM 均最低，比 TSB 低 12.7%、15.2%、21.0%、26.4%，比指数平滑低 14.7%、17.7%、24.5%、30.7%。

梯度说明缺货惩罚越重、分位带宽越关键。LightGBM 的优势不来自点预测（商品层只领先 0.0007），而来自分位形状更贴合需求分布；同水平下四模型满足率 0.982 至 0.985（逐序列等权平均），成本差不是牺牲服务换来的。


## 4.3　覆盖率：唯一的系统性弱点

名义 0.95 实测覆盖：指数平滑 0.9414、TSB 0.9434、季节朴素 0.9373、LightGBM 0.9231，最大偏差 0.0318。23 个水平共 368 行中 39 行偏差超 0.05，最大 0.0933，集中在低分位；LightGBM 偏差方向一致（实际覆盖偏低，即带宽偏窄），要达到 0.94 覆盖需抬到 0.9617。

原因分三层：需求间歇、小样本下经验分位不稳；误差加法假设与销量规模相关，高销量商品分位被压窄；LightGBM 训练目标偏中位，高位尾部样本稀疏，0.95 附近系统性偏低。

可选处理有四条：按分位水平校准残差、高分位保守加宽、按销量规模分层校准、改走调和接口，代价依次是放弃部分分位形状、库存上升、需要更多历史窗口、依赖他人交付。本部分一条都没用于改预测侧分位，而是与模块 02 定案在评估侧做等价映射：插值到名义 0.95 后，5:1 下 LightGBM 0.794、TSB 0.941、指数平滑 0.997、季节朴素 1.171；主线仍报裸分位，无需预测侧重跑。


## 4.4　决策图：分段最优模型并不唯一

按间歇性、生命周期、销量规模三维切分，5:1、0.95 切片上间歇性五段分别落到：块状 TSB 258,263.72、间歇 LightGBM 1,674,658.0、块状高变异 TSB 621,866.1、无需求 LightGBM 11,222.34、平滑 LightGBM 685,822.05。分层选模型成立，但只在块状与间歇两类分化。

相对简单方案的三维节省为 15.86%、31.61%、26.21%，等权 24.56%（先把各维度内分段求均值再等权；若 14 段直接平均为 24.44%，两者不得混用）。1,288 行中不存在最优成本高于简单或参照方案的行。


## 4.5　不确定性与等覆盖率检验

配对重采样（相对季节朴素基线、5:1、0.95，B=200，单位是每条序列四窗口合计的成本差、Co=1）：指数平滑 −22.19（−22.92 至 −21.41）、TSB −28.55（−29.60 至 −27.51）、LightGBM −57.48（−59.45 至 −55.39）。三区间都不跨零，LightGBM 与另两者不重叠。

等覆盖率对照把分位调到实际覆盖 0.92、0.94、0.96 再比：5:1 下 LightGBM 仍全最低（0.688、0.745、0.843），TSB 0.793、0.865、1.016，指数平滑 0.837、0.913、1.081，领先收窄到 13% 至 17%；1:1 的低覆盖端 TSB 反而略优（0.569 对 0.594）。按三点插值补到名义 0.95：LightGBM 0.9689 与 0.794、TSB 0.9558 与 0.941、指数平滑 0.9572 与 0.997、季节朴素 0.9597 与 1.171，领先 15.6%、20.3%、32.2%；代价是 LightGBM 自身成本由 0.694 上浮 14.4%。


## 4.6　分位网格下延与选择规则

理论最优分位等于缺货成本除以缺货与持有之和：1:1 为 0.50、2:1 为 0.67、5:1 为 0.83、9:1 为 0.90，前两者落在任务卡 0.80 至 0.99 网格之外。本版把网格下延到 0.50 并补入 2/3 与 5/6，三个新增点取自模块 02 原生取值，未新增数据需求。

下延后 1:1 与 2:1 的最优分位落在 0.50 与 0.6667，与理论值偏离为零，不再是“网格下界”；5:1 为 TSB 0.85、指数平滑 0.86、LightGBM 0.86、季节朴素 0.87，9:1 为 0.91 至 0.92，均略高于理论值 0.83 与 0.90——分位带宽偏窄，需要额外缓冲才压住缺货。headline 0.95 的数值与下延前逐位相同。

这是一处对任务卡参数的偏离（原网格 0.80 至 0.99）：不下延，1:1 与 2:1 只能写“实测值即网格下界”，两个成本比的结论会失去意义；下延后四个成本比都有真实最优点，headline 不变。


## 4.7　层级调和面板的核验与下单粒度对照

模块 03 交接包三项核验。其一，点预测确做了自下而上调和：顶层 28 天累计由 1,146,624 变为 1,189,844（+3.8%），精确等于 30,490 条叶层点预测之和。其二，28 天累计分位的 bottom_up 输出当前仍是 unreconciled 的拷贝（实现缺口）：bottom_up 与未调和面板逐行相同，顶层、门店层、叶层合计 701,523 条零差异。其三，分位面板自身不成加总关系：门店 CA_1 节点 106,884 对叶求和 124,569，低 14.2%；全体系 τ=0.95 低 35.4%，最大 49.8%。

这里有两个问题要分开：一是 bottom_up 累计分位未实现加总（实现缺口），交付面板与 unreconciled 逐行相同；二是分位不可加，30,490 条序列各自的 95% 分位之和是“每条都按 95% 备货的备货量”，不是“总量需求的 95% 分位”，缺口随水平上升扩大，τ=0.50 只差 2.6%、0.95 差 35.4%。门店层校准（输入为 LightGBM 分位）：τ=0.95 时 10 店中 9 至 10 店被覆盖（0.90 至 1.00），但总量是真实需求的 1.45 至 1.50 倍；τ=0.50 仅 2 店被覆盖（0.20）。总量层方向相反：单一总量节点 τ=0.95 只有真实需求的 0.96 至 0.99，未被覆盖，偏高集中在门店层。高层分位形状偏宽：中位数偏低、尾部偏高。

下单粒度对照沿用同一仿真核，主结果未改。A 按单品下单（现状 headline），B 由门店定总量再按单品点预测占比分摊。5:1、0.95、四窗口合并：成本 A 0.6943、B 0.8620（高 24.1%）；填补率按总需求合并算，A 0.9772 对 B 0.9453（低 3.2 个百分点；按逐序列等权平均则 A 为 0.9824，两种口径不可混用）；订货由 728 万降到 707 万，期末库存由 67.5 万升到 70.1 万，即“总量省了、结构浪费了”。门店层 95% 分位本身够用，问题出在分摊：热销备多、冷门备少，缺货与剩余同时出现。

这组是补充而非替换：17 项正式产物未改，结论仍以单品下单为准。两点限制：只有 LightGBM 两侧都有 28 天累计分位，三基线未纳入；B 口径只用点预测占比分摊，24.1% 是“最朴素分摊”下的结果，不是该口径下界。

按定案另做一次真实调用：本机补齐模块 03 依赖，用其层级映射自建目录（42,840 节点、365,880 条成员关系），以本侧 30,490 条序列的 23 个分位为输入，调其分位调和函数（自下而上）。三条结果：输出与本侧叶层求和最大差为零、叶层数值不变，故单品下单的成本、覆盖率与决策图无需重跑；面板顶层同样等于叶求和，测试窗口 τ=0.95 为 1,826,608.6（真实 1,231,764 的 1.4829 倍）、τ=0.50 为 1,140,163.2（0.9256 倍）；说明该接口只保证节点与叶层加总自洽，修不了门店层分位系统性偏高，故高层诊断仍按点预测口径。


# 5　复核与可复现性


## 5.1　独立复算的结果

# 6　结论与边界


## 6.1　现在即可成立的结论

| 项目（headline 口径） | 季节性朴素 | ETS | TSB | LightGBM |
|---|---|---|---|---|
| 每件需求成本（τ=0.95，5:1） | 1.062 | 0.920 | 0.879 | 0.694 |
| 商品层 WAPE | 0.8752 | 0.7406 | 0.7466 | 0.7399 |
| 实测覆盖率（τ=0.95） | 0.937 | 0.941 | 0.943 | 0.923 |
| 等覆盖率成本（0.94，5:1） | 1.080 | 0.913 | 0.865 | 0.745 |
| 最优服务水平 τ*（成本比 5:1） | 0.87 | 0.86 | 0.85 | 0.86 |

第一条，口径闭合、可复现。成本可由原始预测加参数表完全重算，独立复算误差在浮点量级，任一成本数字都可被第三方复核。

第二条，成本排序由分位质量决定，而非点预测精度。三个现代模型商品层误差只差 0.007（与季节性朴素相差 0.135），每件需求成本却差 12.7% 至 30.7%，差距来自分位带宽与形状。

第三条，LightGBM 在名义 0.95 下四个成本比均最低，但优势并非与覆盖率无关：把覆盖校到 0.92 后，5:1 与 9:1 仍领先 13% 至 24%，1:1 的低覆盖端 TSB 反而低 4.3%；优势随缺货代价上升而扩大。

第四条，分层选模型成立但只在部分形态分化：块状归 TSB、间歇归 LightGBM，平滑与无需求仍归 LightGBM；三维等权节省 24.56%。

第五条，覆盖率是已知弱点且已量化：368 行中 39 行超差、集中在低分位，LightGBM 需抬到 0.9617 才达 0.94 覆盖，处理路径与代价已登记。

第六条，成本对成本比高度敏感，决策必须绑定成本结构。1:1 到 9:1，LightGBM 成本由 0.603 升到 0.785，与 TSB 的差距从 12.7% 扩到 26.4%，最优服务水平也从 0.50 移到 0.92；缺货代价越高，分位质量越值钱。

第七条，最优服务水平可由成本比直接推出。理论值等于缺货成本除以缺货与持有之和，实测 1:1 与 2:1 精确落在 0.50 与 0.6667，5:1 为 0.85 至 0.87，9:1 为 0.91 至 0.92；补货参数因此不必依赖建模细节。

第八条，分层分位结论只能止于叶层。当前 bottom_up 累计分位面板未实现加总（实现缺口）：τ=0.95 时顶层对叶求和低 35.4%、门店 CA_1 低 14.2%、各节点最大 49.8%；这个 35.4% 是 unreconciled 的 gap。即使修正，叶层分位求和也不等于总量分位（1.48× actual），这是分位不可加的统计限制。高层比较改用点预测口径，分位口径不外推到部门门店与州层。

第九条，下单粒度影响成本结构而非总量。门店只定总量再摊到单品，成本高 24.1%、填补率低 3.2 个百分点，订货量反而少 2.9%、期末库存多 3.8%：总量够用、结构错配。

第十条，点预测的调和改变层级自洽，不改变单品级结论。接口实调后叶层数值逐位不变、最大差为零，说明本部分的成本、覆盖率与决策图结论在调和完成后依然成立。


## 6.2　结论的边界

边界有五条。第一，样本为 M5 数据集全部 30,490 条序列（CA 4 家、TX 3 家、WI 3 家门店），覆盖完整但不代表更广泛的数据源。第二，成本按每件需求归一化，绝对金额随抽样规模变化，只有跨组百分比可读。第三，三个基线的周期累计分位由本模块补造，若模块 02 提供官方分位，基线成本会变、领先幅度可能收窄。第四，模块 03 面板已到位但累计分位未调和，分层分位结论止于叶层，部门门店与州层只用点预测口径。第五，日级分位只有四个共同水平、下单粒度对照只有 LightGBM，两处结论的覆盖面有限。


## 6.3　对选型与后续工作的含义

选型上，若补货按单品执行且缺货代价在 1:1 至 9:1 之间，LightGBM 是默认选择；只有块状需求段换用 TSB 更省，且收益集中在少数形态，不宜全表替换。

参数上，服务水平可直接由成本比定：持有与缺货同价取 0.50，缺货为持有两倍取 0.6667，五倍取 0.86，九倍取 0.92，不必再按经验拍 0.95。

改进优先级上，先修分位带宽：LightGBM 覆盖缺口 0.027，抬到等效 0.95 覆盖要付 14.4% 的成本上浮，这笔代价必须计入收益比较；再考虑更细的分位网格；分层调和值得投入的前提是节点层确有系统性偏差（TSB 门店层 WAPE 是 LightGBM 的两倍即此类），单品层的随机误差不在其射程内。
