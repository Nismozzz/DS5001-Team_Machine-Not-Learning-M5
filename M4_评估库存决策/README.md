## 概览



* 评估对象：季节朴素、指数平滑、TSB、LightGBM 四个模型，SKU 层 28 天累计口径为主。

* 仿真口径：提前期为零、缺货不回补、28 天周期内不安排中间补货；首期期初为零，其后各期期初等同上期结转。

* 成本口径：只用成本比（持有：缺货 = 1:1、2:1、5:1、9:1），不依赖绝对价格，因此不受价格缺失影响。

* 正式产物 17 项，验收 11 项全部通过；另有 8 件离线补充（`02_outputs_final/supplement/`）与 1 张补充图，随包存放，不并入正式清单与哈希校验。

## 主要结果



| 指标                        | 结果                                                 |
| ------------------------- | -------------------------------------------------- |
| SKU 层 WAPE（四窗口均值）         | LightGBM 0.7399、指数平滑 0.7406、TSB 0.7466、季节朴素 0.8752 |
| 成本（τ=0.95、5:1、每件需求、四窗口均值） | LightGBM 0.694、TSB 0.879、指数平滑 0.920、季节朴素 1.062     |
| 领先幅度（5:1）                 | 比 TSB 低 21.0%，比指数平滑低 24.5%                         |
| 覆盖率（τ=0.95，LightGBM 四窗口）  | 0.9182 / 0.9259 / 0.9283 / 0.9200，最大偏差 0.0318      |
| 最优服务水平（5:1）               | LightGBM 0.86，TSB 0.85，指数平滑 0.86，季节朴素 0.87         |
| 配对重采样（相对季节朴素、5:1、τ=0.95、B=200） | LightGBM 每条序列平均低 57.48（四窗口合计、Co=1），区间 \[−59.45, −55.39]，显著 |
| 决策图三维段均值                  | 15.86 / 31.61 / 26.21，等权 24.56%                    |

补充结论：



* SKU 层 23 点 pinball 上，LightGBM 在全部 23 个服务水平为四模型最低（门店层与总量层只有 6 个水平最低，补充表已分层列示）。

* 分位不可加：顶层与叶层分位求和在 τ=0.95 时相差 35.4%，测试窗口顶层为真实需求的 1.48 倍。

* 门店只定总量、按点预测占比分摊到单品时，成本由 0.6943 升到 0.8620（高 24.1%），填补率由 0.9772 降到 0.9453。

## 范围与限制



* 样本为 M5 数据集全部 30,490 条序列（CA 4 家、TX 3 家、WI 3 家门店）；成本已按总需求归一化，绝对金额不可外推至其他数据源。

* 日级分位只有 0.5 / 0.9 / 0.95 / 0.99 四个共同水平，四模型横向比较以 28 天累计层 23 点为准。

* 分位数不可加，故分层分位结论止于叶层；高层分层诊断使用点预测口径。

* 模块 03 交付的分位面板未做调和，本模块按方案 A 自建目录并实调自下而上方案，输出与叶层逐层求和一致。

* 只有一个模型在两侧都有 28 天累计分位，下单粒度对照仅覆盖该模型。
